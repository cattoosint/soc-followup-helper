REQUEST DETAILS - SOC nightshift follow-up helper
=================================================
Everything an IT / security reviewer usually asks for, in one place.


WHAT IT IS
  A local Python script an analyst runs on their own laptop. It reads the
  filtered case export, searches each case in Outlook on the web, and opens
  a Reply All draft. The analyst reviews and sends every email themselves.
  It reduces manual copy-pasting for ~300 cases per night shift.


WHAT IS BEING ASKED FOR
  1. Internal PyPI index URL, so pip can install the packages below
     (or have them provisioned on the machine)
  2. A sanctioned way to get the script file onto the SOC laptop
     (email, cloud storage and public code hosting are all blocked)

WHAT IT DOES NOT DO
  * does not send email by itself - the analyst sends every one
  * no mailbox API, app registration, service account or extra permissions;
    it uses the analyst's own Outlook session in the browser
  * no server, database, cloud service, scheduled task or listening port
  * no admin rights; nothing installed into Outlook
  * no credentials stored by the tool - sign-in happens on Microsoft's own
    page, and the session is kept in a local browser profile folder


NETWORK ACCESS
  Outlook on the web only (outlook.cloud.microsoft / outlook.office.com),
  i.e. the same traffic as using Outlook by hand.
  One-off on first run: Selenium fetches a matching chromedriver. If that
  is blocked, a chromedriver.exe can be placed beside the script instead.


DATA HANDLING
  Reads   : the case export the analyst selects
  Writes  : results log (CSV), a colour-coded copy of the sheet (XLSX),
            per-run logs, and failure screenshots - all in its own folder
  These contain case numbers and email subjects, so they carry the same
  classification as the export itself. Nothing is transmitted anywhere.


ASSURANCE
  Ships with two test suites that run offline, with no mailbox access:
      python audit_simulation.py    13 checks, simulated Outlook end-to-end
      python test_edge_cases.py     14 edge cases
  Both print PASS/FAIL per check. Source is a few plain .py files and can
  be read in full - roughly 1,500 lines, no compiled components.
