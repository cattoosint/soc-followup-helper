SOC NIGHTSHIFT FOLLOW-UP
========================

Nothing to install. The libraries it needs are already in the libs folder,
so there is no pip, no downloads and no internet needed to set it up.


WHAT YOU NEED
  * Windows
  * Python 3.10 or newer   (check with:  python --version)
  * Google Chrome


GETTING STARTED
  1. Put this folder somewhere in your own profile, e.g.
         C:\Users\<you>\SOC Followup\
     (not a shared drive - it keeps a signed-in browser session)

  2. Double-click   START HERE.bat
     (or run:  python soc_gui.py)

  3. Click "Sign in to Outlook", log in, and choose "Yes" at
     "Stay signed in?". It is remembered from then on.

  4. Click "Browse..." and pick your filtered case export.
     Save it as .xlsx so the Excel filter is preserved - rows you filtered
     out are skipped.

  5. Click "Check export" - confirms it reads the case numbers correctly.

  6. Set Limit to 2 or 3 for a first run, then "Start follow-ups".


HOW A RUN GOES
  For each case it searches Outlook, opens the Reply All draft, and waits.
  You review, edit and press Send in Outlook. It notices the send, checks
  the reply reached Sent Items, pauses 5 seconds, and moves to the next.

  It never sends an email by itself.

  Cases with no matching mail are flagged, and the run carries on.


AUTO-SEND (optional, off by default)
  Ticking "Auto-send" makes the tool send a reply WITHOUT review, but only
  when BOTH of these are true:

     * the LATEST message in the thread came from the sender you type in
       (email address or display name - either works), and
     * the thread contains the phrase you type in (default: "follow up")

  Anything else still stops and waits for you, exactly as before.

  You must also tick the confirmation box. Note your Outlook signature is
  used as-is, so check it is correct before turning this on.

  The sender you type is saved in soc_settings.json beside the tool. That
  file is local only - it is never included in the shared package.

  Every decision is written to the log, e.g.
      auto-send check for 612100: SEND (matched 'follow up'; latest mail
      is from 'alerts@example.com')
      auto-send check for 612002: manual (latest mail is not from ...)

  Auto-sent replies are still verified in Sent Items, and appear in the
  results as "(auto-sent)".


WHAT IT PRODUCES (all in this folder)
  followup_review_*.xlsx   your sheet, colour-coded:
                             green  = replied
                             red    = no mail found / error - needs a human
                             amber  = you skipped it
                             yellow = run stopped before reaching it
  followup_results_*.csv   every case and its outcome
  logs\                    detailed log of each run
  screenshots\             only written when something fails
  uc_profile\              the signed-in browser session. Treat like a
                           saved password: one per analyst, do not share.

  The "Review sheet" button rebuilds the colour-coded sheet at any point,
  including mid-run.


CHECKING IT WORKS - no mailbox needed
  python audit_simulation.py     13 checks against a simulated Outlook
  python test_edge_cases.py      14 edge cases

  Both run offline and print PASS/FAIL per check. Worth running once after
  copying the folder, to confirm everything arrived intact.


IF SOMETHING GOES WRONG
  Click "Save diagnostics" - it writes a zip with the logs, any failure
  screenshots and the run results. That is the file to send for help.
  It contains case numbers and email subjects, so handle it like the case
  export itself. The signed-in browser session is never included.

  If Chrome fails to start, check the driver:

      python soc_followup.py --csv x --driver-info

  Drivers for Chrome 150 and 151 ship in the drivers folder and are picked
  automatically. If your Chrome is a different major version, that command
  tells you so and gives the download page - grab the win64 driver for your
  version from:

      https://googlechromelabs.github.io/chrome-for-testing/

  and drop it in this folder as chromedriver.exe. Your Chrome version is at
  chrome://settings/help


NOTES
  * Uses your own Outlook session in the browser - no mailbox permissions,
    no app registration, no admin rights, nothing installed into Outlook.
  * The "Undetected browser mode" tick-box is only for personal mailboxes
    that keep signing out. Leave it off at work.
